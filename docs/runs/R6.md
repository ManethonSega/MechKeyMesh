# R6: Normal-layer remapping

## Status

**IN PROGRESS**

R6 is the first substantial OEM-replacement feature. It adds durable normal-layer assignments and writes the complete AULA F108 Pro mapping table through the verified USB transaction.

## Protocol

The normal layer uses:

```text
04 18                     begin, readback
04 11, byte[8] = 09       normal-map init, readback
576-byte table            9 x 64-byte reports, readback
04 02                     apply, readback
04 F0                     finalize, readback
```

The 576-byte table contains 144 four-byte slots. Slot position is:

```text
device key index * 4
```

Slot 0 is unused. The final two bytes are the verified remap-table trailer:

```text
AA 55
```

This byte order is specific to the little-endian remap-table uint16 `0x55AA`. It is not generalized to other F108 packet families.

## Implemented action encodings

### Default

```text
00 00 00 00
```

### Disable key

```text
05 03 00 00
```

### Keyboard key, modifier and shortcut

```text
02 modifier-mask HID-usage 00
```

Modifier bits:

| Modifier | Bit |
|---|---:|
| Left Ctrl | 01 |
| Left Shift | 02 |
| Left Alt | 04 |
| Left Win | 08 |
| Right Ctrl | 10 |
| Right Shift | 20 |
| Right Alt | 40 |
| Right Win | 80 |

A modifier assigned by itself uses its bit with HID usage zero.

### Media

Action type `03` with the consumer usage stored little-endian. R6 enables:

- Play/Pause
- Stop
- Previous track
- Next track
- Volume Up
- Volume Down
- Mute

### Mouse

Action type `07`. R6 enables only currently mapped values:

- Left click
- Right click
- Middle click
- Scroll up
- Scroll down

Double click, Mouse Button 4 and Mouse Button 5 remain disabled because their F108 slot values are not verified.

### Windows/system

R6 enables verified mappings:

- Show Desktop, Win+D
- Computer/File Explorer, Win+E
- Lock, Win+L
- Close Window, Ctrl+W
- Switch Window, Alt+Tab
- Calculator

Log Off, Sleep, Shutdown and Restart remain disabled because their normal-map slot values are not verified.

## Host-side OEM actions

The OEM software presents:

- Open Program
- Open File
- Open Website
- Send Text

Static analysis shows that these use type `05 02 index 00`, where the index refers to an OEM host-side action list. The four-byte keyboard mapping alone is not sufficient to recreate the behavior.

R6 therefore models these action families but keeps them disabled until MechKeyMesh independently verifies and implements the host event channel. This is more accurate than exposing controls that ACK but do nothing.

Macros remain disabled until the macro-bank runs.

## Desired-state persistence

Normal assignments are stored in the existing `key_mappings` table under:

```text
device model = aula.f108pro
profile      = default
capability   = keys
layer        = normal
```

Saving replaces the normal layer transactionally. Default actions are omitted from SQLite, so an empty stored map means every key uses firmware default behavior.

The database is written before hardware application. A disconnected keyboard therefore does not discard the desired keymap.

## UI

The Keys page supports:

- single selection
- Ctrl/Cmd multi-selection
- action family editor
- reset selected
- copy and paste action
- undo
- redo
- mapped-key visual state
- save complete desired normal layer
- apply the complete table through Device Manager when the keyboard is ready

## Automated safety

R6 validates the entire table before sending any HID report:

- valid normal layer
- unique device key indices
- indices do not overlap the trailer
- every action is supported by the F108 R6 encoder
- HID usages fit the four-byte slot
- unverified actions are rejected
- trailer is exactly `AA 55`

The Device Manager serializes the remap transaction with lighting and future hardware operations. It does not automatically replay a partly transmitted keymap.

## Physical verification

ACK means only that transport succeeded. It does not prove the remapped key produces the requested Windows input.
