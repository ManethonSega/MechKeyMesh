# R16: LCD hardware upload

R16 connects the validated R15 asset to the F108 Pro USB hardware. This is a high-risk path and stays dynamically unavailable unless the dedicated LCD interface is present.

## Verified transport contract

| Channel | Usage | Report |
| --- | --- | ---: |
| Configuration HID | `FF13` | 64-byte feature reports |
| LCD interrupt HID | `FF68`, interface 2 | 4096-byte output pages and 64-byte input acknowledgments |

The wired sequence is `04 18` begin, `04 72` upload header, all 4096-byte pages with a required `01 5A 02 00` acknowledgment, then `04 02` apply. The data pages are never sent as feature/control transfers.

## Preflight

Before the first packet, the driver verifies all of the following:

- active device is the wired F108 Pro VID `0C45`, PID `800A`
- dedicated `FF68` interface was discovered and opened
- dimensions are exactly 240 × 135
- pixel format is RGB565 little-endian
- frame count is within 1 through 141
- header is exactly 256 bytes
- metadata frame count equals header frame count
- every delay byte is nonzero and every unused header byte is `FF`
- content length, padded payload length and page count are exact

The device manager serializes the transfer with all other persistent operations. There is no competing LCD transaction.

## Recovery and UI

The UI reports acknowledged pages, permits cancellation, applies a 300 ms per-page ACK timeout, and retains an incomplete-transfer warning after cancellation, timeout or disconnect. Cancellation never sends the final apply command. Reconnect and a complete new upload are required after an incomplete transfer.

Clock sync uses the verified `04 18`, `04 28`, date/time data and `04 02` sequence. It is exposed only for USB.

## Validation status

Automated tests cover exact 141-frame acceptance and rejection of frame 142, wrong header counts and wrong page lengths before transport access. Physical repeated uploads of a still image, short animation, 141-frame animation and converted video remain pending. No physical keyboard is available in this environment, so R16 must not be described as hardware-verified yet.
