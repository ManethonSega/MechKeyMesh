# Desktop UI revision · 0.20.0-alpha.6

The old interface exposed run numbers, raw protocol notes and database metrics alongside everyday controls. This revision makes the user’s tasks easier to find and makes the difference between a local edit, a saved configuration and a hardware write explicit.

## Design guidance used

- Impeccable: operate-mode hierarchy, clear copy, quieter surfaces and progressive disclosure. Existing brand and vanilla HTML/CSS/JavaScript stack retained.
- Web Design Guidelines: semantic labels, visible keyboard focus, skip navigation, status announcements, native controls, dark color-scheme and destructive-action confirmation.
- UI/UX Pro Max: consistent control sizes, semantic colors, paired light/dark themes, empty states and layouts for the supported desktop sizes.
- Emil Design Engineering: responsive interactions, restrained hover transitions, reduced-motion support, transform-based spectrum meters and no artificial startup delay.

## Changes

- Navigation groups Keyboard, Personalize and Application; removes R-number badges from product UI.
- Overview prioritizes connection, profile, battery where supported and honest charging availability. Key assignments, lighting and LCD are directly accessible.
- Technical connection/storage and key/protocol details remain available in expandable sections.
- Lighting/settings track actual drafts. Pending operations lock their fields and action buttons until completion. Saving locally does not claim the hardware was changed or physically verified. Failures retain edits.
- Lighting options load before the saved mode and direction are restored. Startup errors reveal the app with a recoverable notice instead of leaving the splash visible indefinitely.
- Native application and media pickers remain unchanged. Profile fields have visible labels, application rules have a helpful empty state, and saved macro/profile/rule deletion is cancellable.
- Keyboard-layer tabs support arrows, Home and End. Navigation updates its accessible current state and moves focus to the page heading.
- Typography, spacing, controls, focus, semantic status colors and compact-window layouts share a final stylesheet. The supplied transparent PNG and generated Windows icons are unchanged.
