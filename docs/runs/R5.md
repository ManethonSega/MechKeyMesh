## Parameter model

R5 uses driver-provided effect metadata rather than hard-coded frontend assumptions.

The known F108 mode table maps to:

| Modes | Color | Rainbow toggle | Brightness | Speed | Direction |
|---|---|---:|---:|---:|---|
| 0 Off | No | No | No | No | No |
| 1 Static | Yes | Yes | Yes | No | No |
| 2-5 | Yes | Yes | Yes | Yes | No |

| 7 Breath | Yes | Yes | Yes | Yes | No |

The source software encoded these controls using per-mode `config_func` values. R5 preserves the behavior without copying OEM presentation assets.

## Safety behavior

The driver sanitizes every outgoing lighting packet according to the selected mode.

Examples:

- Static always sends speed = 0 and direction = 0.
- Colourful and Spectrum ignore stale RGB and rainbow-toggle values.
- Non-directional modes always send direction = 0.
- Off clears every effect parameter.

Therefore UI-hidden values cannot accidentally remain active in the protocol payload.
